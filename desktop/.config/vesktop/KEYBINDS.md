The most important keybinds for Discord

|||
-|-
Up | Edit last message
Ctrl-K | Quick switcher
Alt-Left/Right | Back/Forward
Alt-Up/Down | Prev/Next Channel
Ctrl-Alt-Up/Down | Prev/Next Server
Shift-Alt-Up/Down | Prev/Next Unread
Tab | Selection mode
Esc | Focus text box
R | Reply to selected message
E | Edit selected message
BkSp | Delete selected message
