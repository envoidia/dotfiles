# Zed Keybinds

# Navigation
| Text || 
-|-
Up/Down/Left/Right | Move cursor
Ctrl-Up/Down | Scroll view
Ctrl | Navigate symbol-wise
Alt | Navigate word-wise
Home/End | To line home/end
Hypr-Up/Down | Move up/down 10 lines
Hypr-Left/Right | To start/end of larger syntax node
Ctrl-G | To line
Ctrl-U | Cursor undo
Ctrl-Shift-U | Cursor redo
Ctrl-Home/End | To file home/end
F7 | To next match of highlight
Shift-F7 | To previous match of highlight
Tab | Indent
Shift-Tab | Outdent

| Selection || 
-|-
Shift | Select while navigating
Ctrl-C | Copy
Ctrl-X | Cut
Ctrl-V | Paste
Ctrl-A | Select All

| Deletion || 
-|-
BkSp | Delete left
Del | Delete right
Ctrl-Shift-BkSp | Delete all left
Ctrl-Shift-Del | Delete all right

| Lines || 
-|-
Alt-Up/Down | Move line
Ctrl-Alt-Up/Down | Duplicate line
Ctrl-L | Select line
Ctrl-/ | Comment/uncomment line/selection
Ctrk-Shift-K | Delete line
Ctrl-[ | Outdent line
Ctrl-] | Indent line

| Tabs || 
-|-
Ctrl-Tab | Switch between tabs
Ctrl-Shift-T | Reopen last closed tab
Ctrl-PgUp/PgDown | To prev/next tab
Ctrl-Shift-PgUp/PgDown | Move tab left/right
Alt-{Num} | To {Num} tab
Ctrl-N | New file
Ctrl-P | Open file in project
Ctrl-O | Open file
Ctrl-W | Close Tab

| Groups || 
-|-
Ctrl-\  | Move tab to right group
Ctrl-Alt-\  | Move tab to left group
Ctrl-Shift-\  | Split tab to right group
Ctrl-Shift-Alt-\  | Split tab to left group
Ctrl-{Num} | To {Num} group
Ctrl-Alt-Left/Right | Move tab to prev/next group
Ctrl-K Left/Right | Move group left/right

| Multicursor || 
-|-
Ctrl-Shift-Up/Down | Create cursor up/down
Alt-Click | Create cursor there
Esc | Remove extra cursors

# Code
| Navigation || 
-|-
F1 | To definition/uses
Ctrl-T | To symbol
Ctrl-Shift-T | To symbol in workspace
Ctrl-. | Context actions
Ctrl-H | Show hover
F2 | Rename symbol
Alt-P | Show diagnostics
F8 | To next diagnostic
Shift-F8 | To prev diagnostic
Alt-Enter | Open file from references/search view

| Folding || 
-|-
Ctrl-Shift-[ | Fold
Ctrl-Shift-] | Unfold
Ctrl-K Ctrl-0 | Fold all
Ctrl-K Ctrl-J | Unfold all
Ctrl-K Ctrl-{Num} | Fold level {Num}

| Debugging || 
-|-
F5 | Run and debug
Ctrl-F5 | Run without debugging
Shift-F5 | Stop debugging
Ctrl-Shift-F5 | Restart debugging
F6 | Pause
F9 | Toggle breakpoint
Shift-F9 | Toggle log breakpoint
Shift-F11 | Step out
Ctrl-F11 | Step into

Ctrl-Shift-F2 | Solution explorer rename
Hypr-G | Git
Hypr-D | Debug
Hypr-O | Outline
Hypr-X | Extensions

| Bottom Panel || 
-|-

Ctrl-S | Search editor apply changes
F3 | Find next
Shift-F3 | Find previous

Ctrl-Z | Undo
Ctrl-Y | Redo
Ctrl-Shift-P | Command palette
Ctrl-, | Settings
Ctrl-K Ctrl-S | Keybinds
Ctrl-Alt-V | Preview markdown
Ctrl-Shift-V | Preview markdown to the side
Ctrl-Shift-N | New window
